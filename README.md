# 📝 NotesApp (Clean Swift Edition)

Легкое и масштабируемое приложение для управления заметками, построенное на архитектуре **Clean Swift (VIP)**. Данные загружаются из сети и синхронизируются в реальном времени.

## 🏛 Архитектура: Clean Swift (VIP)

Проект строго следует циклу **View -> Interactor -> Presenter**:

* **ViewController (View):** Отображает данные и передает действия пользователя Интерактору.
* **Interactor:** Содержит всю бизнес-логику (загрузка из сети, удаление, валидация).
* **Presenter:** Форматирует данные, полученные от Интерактора, в удобный для отображения вид (ViewModel) и передает их контроллеру.
* **Worker:** Выполняет конкретные задачи, такие как сетевые запросы через `URLSession`.
* **Router:** Отвечает за навигацию между экранами и передачу данных.

## 🛠 Технологический стек

* **UI Framework:** UIKit (верстка кодом / Storyboard — *выбери свое*)
* **Language:** Swift 5.9+
* **Architecture:** Clean Swift (VIP)
* **Networking:** URLSession (Native networking без сторонних библиотек)
* **Data Format:** JSON (Codable protocol)

## 🚀 Функционал

-   ✅ **Загрузка заметок:** Получение актуального списка через удаленный API.
-   ✅ **Добавление:** Создание новой заметки и отправка на сервер.
-   ✅ **Удаление:** Интуитивное удаление заметок (Swipe-to-delete).
-   ✅ **Обработка состояний:** Реализованы состояния загрузки (Loading), ошибки (Error) и пустого списка.
